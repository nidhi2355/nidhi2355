## 🧠 What i'm about

I'm a CS undergrad who got hooked on the idea that AI is only as good as the pipeline behind it — chunking, retrieval, latency, cost. Most of my projects live in that space: taking an LLM from "cool demo" to something that actually holds up under memory limits, cold starts, and messy real-world data.

When I'm not doing that, I'm grinding DSA or trying to make a dashboard look less ugly than my first attempt.

### 🩺 CardioX AI
**RAG-based heart health assistant**

Turned 10+ medical PDFs into a queryable knowledge base — LangChain + FastAPI + Groq-hosted Llama 3.1, chunked and embedded into FAISS via HuggingFace `all-MiniLM-L6-v2`.

- 🎯 90%+ context retrieval accuracy
- ⚡ 40% faster than keyword search
- 🗣️ Explains medical jargon in plain English *and* Hinglish

[`→ view repo`](https://github.com/nidhi2355/cardiox-ai)
